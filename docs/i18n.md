# Internationalisation

- Langues : `fr` (défaut) et `en`.
- `proxy.ts` : si l'URL n'a pas de préfixe de langue, détecte la langue du navigateur (`negotiator` + `@formatjs/intl-localematcher`) et redirige vers `/{locale}`. Assets et routes API exclus par le `matcher`.
- `app/recup-dictionnaire.ts` : `getDictionary(locale)` charge dynamiquement le JSON (repli sur `fr`). Le type `Dictionary` est dérivé de `fr.json`.
- Les deux dictionnaires doivent avoir **exactement les mêmes clés**.

## Ajouter une langue
1. Créer `app/dictionnaires/<code>.json` avec les mêmes clés.
2. L'ajouter dans `dictionaries` (`recup-dictionnaire.ts`) et dans `locales` (`proxy.ts`).

## Limites actuelles
- `<html lang>` est fixé à `fr` dans `layout.tsx`.
- La liste des locales est dupliquée entre `proxy.ts` et `recup-dictionnaire.ts`.
